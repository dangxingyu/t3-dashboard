局部机制 · AdamW 如何改变适应梯度

64 个状态 · 512 个 TRAIN 三元组 · 已核验

原始梯度差异存在，动量和自适应更新使相对差异缩小

相对向量差异的平均值：原始 query 梯度 10.53%，裁剪后 10.49%，一阶动量 3.41%，AdamW 自适应分量 1.23%。实际存储的 FP32 参数位移差异为 3.69%，受舍入影响，不能与自适应分量混同。这里测的是相同权重与旧动量下的一次局部更新。

每个阶段使用自己的 zero 向量作为分母。裁剪后到自适应分量的相对差异比值平均为 0.127；512 个记录全部小于 1。这些记录彼此依赖，不代表 512 个独立重复实验。完整向量图 PDF ↗

局部 loss 差异很小，不能当作实际 CPT 成功

原生 AdamW 的平均 FineWeb NLL 差值仅 −5.63×10⁻⁸，512 个记录中 249 个完全相同。移除自适应缩放或动量的对照使平均遗忘差异变大，同时平均 query loss 变差；它们没有证明可以同时学得更多、忘得更少。

两种对照按 zero Adam 自适应分量的范数校准，共用权重衰减；不保证实际 FP32 位移相等。仅观察 warmup 的第32步与末尾状态，末尾测的是假想额外一步；不能据此解释整个训练轨迹或 Muon。新增成本 1.699 GPU小时。下一步先检查固定内层步长下放大梯度修正的局部响应，再决定训练范围。完整局部 loss 图 PDF ↗

实验计划 · 按研究价值排序

术语与读图说明
Own-zero / split-zero
保留 support/query 分割与执行路径，临时适应幅度设为零，用来测量适应本身的增量。
Retained-mean
原始 support 梯度与适应后 query 梯度各占一半。
Query-only
外层只使用 query 梯度，因此必须和自己的 query-only zero 对照比较。
Generalization 与效率
这里主要比较相同数据暴露下的学习与遗忘。额外内层步数会增加工作量，不能由这组结果直接推断计算加速。

计划 → 已准备 → 运行 → 训练完成 → 外部评估 → 科学接受。当前曲线来自 development，单 seed 的文档区间不等于 seed 不确定性。
